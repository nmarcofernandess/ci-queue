# Consumer testing method

Read the consumer's README and AGENTS first, then follow the map path they name.
Use feedback only when the map enables a real recipe present in `ci-queue.json`.
Otherwise use the consumer's declared proof entry or ask its owner to define a
real recipe before enabling feedback.

Before resuming, verify host, cwd, installed revision, state root, session and
ticket. Follow the consumer-owned method for its environment and cleanup.
Feedback is a focal iteration result; proof and ship eligibility come from the
consumer's catalog and delivery contract. Do not invent commands or duplicate
the queue's ticket and ship formats here.

See the generic procedure in [TESTING-METHOD](../../docs/TESTING-METHOD.md).
